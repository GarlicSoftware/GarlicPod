# GarlicPod Aqua artwork

Approved mascot: cream garlic bulb with aqua headphones, green sprout, and dark teal background.

- Originals: approved 1254 x 1254 square PNG and generated transparent cutout. Preserve these masters.
- PNG: 64, 128, 256, 512, 1024 px square icons for documents and general use.
- Transparent: matching PNG cutouts for websites, layouts, and overlays.
- Web: 256/512/1024 WebP, 1024 JPG social image, 180 px Apple touch icon, 192/512 web app icons, and a multi-size favicon.ico (16-256 px). Rename web icons when wiring into a website.
- Print: native-size PNGs tagged 300 dpi. The approved 1254 px square is 4.18 inches at 300 dpi. Larger output needs more source resolution; these are raster artwork, not vector files.
- Android: density-specific legacy icons plus padded adaptive foreground and monochrome themed-icon layers. Adaptive layers are 432 px for a 108 dp canvas at xxxhdpi.

Created with the built-in image generation tool; exports resized/encoded with Sharp. No artificial vector SVG supplied.

Design prompt: Friendly playful cream garlic mascot, oversized aqua/turquoise headphones, green sprout, expressive eyes and smile, bold dark outlines, deep teal background, no text.
Transparent revision prompt: Remove only the dark teal background, preserving the mascot and headphones, with transparent gaps under the headband.
